    零基础建站教程

    我如何用 69 元做出自己的网站：阿里云域名 + GitHub 免费托管，全程不写代码。

    阅读教程 →

    为什么是 69 元？

    网站托管在 GitHub Pages 上，完全免费；唯一要花钱的是域名——在阿里云买一个 .com 域名，一年 69 元。海外托管，个人网站不需要备案。

    第一步：买域名

    在阿里云（万网）搜一个你喜欢的名字。买完马上做实名认证——不认证域名会被冻结，后面解析不了。

    第二步：建 GitHub 仓库

    注册 GitHub（免费），新建一个仓库，仓库名必须叫 你的用户名.github.io，然后把写好的 index.html 网页文件直接拖进去上传。

    第三步：开启 Pages

    仓库的 Settings → Pages，选择 main 分支保存。几分钟后 GitHub 会送你一个免费网址：https://你的用户名.github.io。

    第四步：绑定自己的域名

    回到阿里云「公网权威解析」，加 5 条记录：1 条 CNAME（www → 你的用户名.github.io），4 条 A 记录（@ → 185.199.108/109/110/111.153）。再回 GitHub 的 Custom domain 填上域名，勾选 Enforce HTTPS。

    第五步：等证书生效

    DNS 生效要几分钟到几小时，HTTPS 证书由 GitHub 自动签发。仓库首页出现绿勾、浏览器地址栏出现小锁🔒，就大功告成。

    我踩过的 4 个坑

    1. 域名没实名 → 解析被冻结，先认证再解析；
    2. 解析刚加完就访问 → 打不开是正常的，要等；
    3. 网页文件名必须叫 index.html；
    4. 改网站内容 = 替换 index.html 再上传一次。
